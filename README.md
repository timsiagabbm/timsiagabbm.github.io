# SIAGA BBM

Sistem peringatan dini gangguan mutu BBM beretanol yang memadukan sensor kapasitif untuk sampel tangki dan laporan mekanik bengkel. Dibuat untuk penelitian IKMS 2026, Politeknik Elektronika Negeri Surabaya.

Web: https://timsiagabbm.github.io

Angka bertanda simulasi berasal dari full paper tim dan bukan hasil pengukuran lapangan.
